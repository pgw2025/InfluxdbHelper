# InfluxDB 助手 —— 前后端分离版

基于 **Vue3 + Element Plus** 前端与 **ASP.NET Core 8 Web API** 后端的 InfluxDB 数据统计工具。

## 项目结构

```
InfluxdbHelper.sln
├── InfluxdbHelper/          # 旧版 Razor Pages（迁移期保留，可对照运行）
├── InfluxdbHelper.Core/     # 业务核心类库：Services / Models / DTOs / BackgroundServices
├── InfluxdbHelper.Api/      # 新版 Web API（JWT 认证 + Swagger）
└── influxdb-web/            # 新版 Vue3 前端（Vite + TS + Element Plus）
```

## 快速开始（开发环境）

### 1. 启动后端（端口 5100）

```bash
dotnet run --project InfluxdbHelper.Api
```

- Swagger 地址：http://localhost:5100/swagger
- 默认账号：`admin` / `admin123`（存于 `InfluxdbHelper.Api/appsettings.json`，SHA256 哈希）

### 2. 启动前端（端口 5173）

```bash
cd influxdb-web
npm install       # 已配置 npmmirror 国内镜像源
npm run dev
```

- 访问：http://localhost:5173
- Vite 已配置代理：`/api` → `http://localhost:5100`，无需处理跨域

### 3. 生产构建

```bash
# 前端打包（产物在 influxdb-web/dist）
cd influxdb-web && npm run build

# 后端发布
dotnet publish InfluxdbHelper.Api -c Release -o ./publish
```

## 生产部署（Nginx 反代）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /var/www/influxdb-web;   # 指向 dist 目录
        try_files $uri $uri/ /index.html;
    }

    # API 反代到 Kestrel
    location /api/ {
        proxy_pass         http://127.0.0.1:5100;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
    }
}
```

后端建议用 systemd / Windows 服务 常驻：

```bash
# systemd 示例（Linux）
[Unit]
Description=InfluxdbHelper API
After=network.target

[Service]
WorkingDirectory=/opt/influxdb-helper
ExecStart=/usr/bin/dotnet /opt/influxdb-helper/InfluxdbHelper.Api.dll
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

## 配置说明（InfluxdbHelper.Api/appsettings.json）

| 节点 | 说明 |
|---|---|
| `Auth:Users` | 登录用户列表（PasswordHash 为 SHA256，修改密码可用 `printf '%s' '新密码' \| sha256sum` 生成） |
| `Jwt` | 签名密钥 / 签发者 / 受众 / 过期时间（默认 8 小时） |
| `InfluxDBConfig` | InfluxDB 地址、Token、Org、Bucket（可在前端"系统配置"页在线修改） |
| `DingTalkConfig` | 钉钉机器人推送（Webhook + 加签密钥 + 推送时间 + 消息模板） |

> 敏感字段（InfluxDB Token / 钉钉加签密钥）在 API 返回时自动脱敏，保存时留空即沿用现有值。

## 与旧版的差异

- 全部页面改为 SPA，分页 / 筛选不再整页刷新
- 统计页新增 ECharts 分布图表与占比进度条
- 所有接口需携带 `Authorization: Bearer <token>`（登录页自动获取）
- 配置页保存时可选择是否写入 `appsettings.json`（容器/只读目录下可关闭）
